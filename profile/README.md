# Spec0

**Every API in your company — finally in one place.**

Spec0 is the AI-native API platform — catalog, AI reviews, AI changelogs,
natural-language search, and team-to-team subscriber contracts. AI-native
at every step, running on the OpenAI or Anthropic account you already trust.

## Open source

The pieces of Spec0 that run on your machines are open source and
self-hostable:

- **[mock-server](https://github.com/spec-0/mock-server)** — Schema-correct
  OpenAPI mock server with a bundled web UI. Run in your VPC, in CI, or
  anywhere a JVM goes.
- **[cli](https://github.com/spec-0/cli)** — The `spec0` CLI for publishing
  specs from CI, generating clients, and running quality gates.

## Hosted platform

The catalog, AI workflows, BYO-LLM provider integration, MCP for AI agents,
